# AfriTalent

Plateforme de mise en relation entre freelances tech et entreprises en Afrique.

## Description

AfriTalent est un site vitrine développé dans le cadre du projet de fin de semestre 2. Il permet de présenter une plateforme fictive de mise en relation entre freelances tech et entreprises, avec des fonctionnalités modernes comme le mode clair/sombre, le filtrage dynamique, et des animations au scroll.

## Technologies utilisées

- **HTML5** - Structure sémantique et accessibilité
- **CSS3** - Flexbox, Grid, Bento Grid, animations, responsive
- **Bootstrap 5** - Navbar, cards, carousel, accordion
- **JavaScript (Vanilla)** - DOM, événements, IntersectionObserver
- **Git & GitHub** - Versioning et déploiement

## Fonctionnalités principales

-  Navigation responsive avec navbar fixe
-  Mode clair/sombre avec persistance localStorage
-  Compteurs animés au scroll
-  Filtrage dynamique des freelances
-  Validation de formulaire côté client
-  Animations fade-in au scroll
-  Bouton retour en haut
-  Carousel de témoignages
-  Bento Grid pour la section "Comment ça marche"
